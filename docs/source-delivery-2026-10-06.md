## 开发入口与发布边界

在 `packages/` 运行冻结安装、`bun run test`、`bun run typecheck` 与 `bun run verify:pack`。各插件及示例使用自己目录中的脚本和依赖。新 Deflate 与待审计算入口见[送审规范](plugin-submission-v1.md)。

批准种子保持原样。离线计算不产生审批，受控包仍需要绑定完整输入和最终摘要的独立 SOURCE 审查，再执行正常双打包。平台批准、签名、真实 Host 安装、用户授权、模型业务验收和商店发布须分别完成。

公开提交只包含插件、开发工具、公开规范和第三方许可。实际提交身份、私人审查材料、原始迁移清单、生产配置与构建产物保持本地忽略。网站是否部署此源码版本，以[公开版本标识](https://open.reai.com/release.json)和实际页面为准。
