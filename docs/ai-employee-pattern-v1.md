# AI 员工三阶段插件范式 v1

> 记录日期：2026-10-08。对应 `plugins/ai-employee` 本地 Demo。
>
> 范式定义逻辑职责，不规定三个页面、三个数据库或三个进程。真实模型与平台权限按独立合同验收。

本实践用同一套业务核心支撑不同岗位。岗位配置定义资料格式、标准字段、展示模板、公司要求与 Agent 经验。新岗位通过新插件身份和默认配置形成自己的界面。原始资料、标准记录与 Agent 保持同一关系：原始资料提供事实，标准记录承载整理和人工更正，Agent 读取这些依据并生成分析或报告草稿。

## 1. 三阶段职责

| 阶段 | 输入与输出 | 不变量 | 本 Demo 的实现 |
| --- | --- | --- | --- |
| 原始资料 | 人工选择或粘贴资料，形成来源对象 | 原始字节与内容摘要保持不变，后续修改不能覆盖原件 | 文本及二进制原件保存、SHA-256 去重、原件读取 |
| 标准记录 | 资料按岗位字段整理，形成可编辑记录 | 每条记录关联来源或明确标为人工创建，每次修改产生新版本 | 字段别名、类型校验、整数分金额、复核问题、编辑、归档、历史 |
| 岗位 Agent | 岗位经验、公司配置和有界记录上下文，形成建议或报告 | 资料文本不能改变系统指令，分析与业务写入分开，结论保留依据 | 多轮文字窗口、规则演示适配器、Host v2 适配器、确认保存报告 |

原始资料的“不可变”是应用层约束。Demo 不包含数据库 WORM、可信时间戳或外部审计证明。标准记录归档不删除原件。导入异常行时，本次整理不会发布部分有效记录，界面保留问题供复核。

## 2. 数据合同与保存

来源由内容摘要标识，保留文件名、原始字节、导入时间和处理状态。同样字节只保存一次。标准记录使用岗位字段与来源引用，修改时检查期望版本，避免用旧页面覆盖新修改。报告是独立派生对象，记录来源和读取过的记录版本。

真实插件通过 Host 的 `storage.kv@1` 保存到本插件独立的 `employee` store。HTML 预览通过浏览器本地存储运行同一业务逻辑。浏览器预览和 Host 存储不是同一数据实例，不能视为已经迁移或同步。

原始文件、标准记录、公司配置和密码不进入 `.reaiapp` 静态资源。Demo 支持每份最多 128 KiB 的小型资料，接受文本、PDF、图片和办公文档原件。自动整理仅适用于 CSV / JSON，不提取 PDF、图片或办公文档内容。它使用有界对象保存。生产扩展应评估事务、并发、多用户权限、备份、保留与删除策略，再选择本地数据库、云数据库、向量库或图数据库。更换保存后端不能取消来源和版本合同。

## 3. 设置与开发模式

所有配置入口集中在设置页。普通用户设置公司名称、公司约束与展示偏好。开发者输入自己设置的密码后，编辑岗位范式。密码解锁只控制当前配置界面，不能代替公司账号、平台授权或数据库权限。刷新与重新打开界面会锁定开发模式。

| 配置范围 | 内容 | 导出与执行边界 |
| --- | --- | --- |
| 公司配置 | 公司名称、适用地区、业务要求与展示偏好 | 作为本实例配置保存，岗位配置导出不包含它 |
| 岗位字段 | 字段键、中文标签、类型、必填、别名、选项 | 驱动清洗、校验与记录列，已有记录的结构不得直接改写 |
| Agent 配置 | 提示词、inline Skill、SOP、工具引用 | Skill 是说明文字，工具引用仍须 Host 支持与批准 |
| 界面配置 | 配色、Logo 文字、CSS、HTML 模板 | 禁止活动脚本与外部资源，HTML 仅用于受限制的展示 |

岗位配置格式为 `schemaVersion: 1`。定义位于 `src/domain.ts` 的 `EmployeeProfile`，默认入口为 `src/profiles/default-profile.json`。导入执行严格字段白名单和容量校验。附加密码、凭据、原始资料或未知字段会被拒绝。Schema 变更需要新的兼容方案，不得用岗位切换重解释已有记录。

HTML 通用变量为 `{{company}}`、`{{role}}`、`{{jobTitle}}`、`{{recordCount}}`、`{{sourceCount}}` 和 `{{reportCount}}`。财务变量为 `{{income}}`、`{{expense}}`、`{{net}}` 和 `{{pendingInvoices}}`。人事变量为 `{{activeEmployees}}` 和 `{{departmentCount}}`。统计仅读取当前岗位的未归档记录。模板将这些值作为文字插入，不解释为 HTML。CSS 仅设置岗位展示容器内的允许属性。当前不支持脚本、外部链接、表单和动态业务操作。

## 4. Agent 与经验合同

岗位提示词说明职责和输出要求。公司配置说明本实例的目标与限制。Skill 与 SOP 说明处理程序。原始资料及标准记录属于不可信输入，即使资料含有“忽略规则”等内容，也不能作为权限或系统指令。

默认包使用规则演示适配器，界面明确标注其模式。它用于验证输入、分析、报告确认和保存的完整交互。它不调用大模型，也不验证税务或法律结论。

真实适配器使用 Agent Service v2，省略 runtime 时遵循 Host 默认。它固定使用授权范围内的只读标准记录，限制上下文容量，返回文字分析。当前工具集必须为空，非空工具引用会被拒绝。Agent 不执行记录写入，不访问任意工作目录。inline Skill 不等同按需技能执行。

真实模型路径需要 `agent.session@2` 和 `cloud.model.invoke@1` 的平台批准与用户同意。还需受管运行组件、有效外脑 OAuth 会话和匹配的 Host 版本。普通插件自行声明 Manifest 时，CLI / Host 应按合同拒绝未批准能力。详见 [Agent Service v2](agent-service-v2.md) 和 [开发规范](plugin-development-v1.md)。

语音当前不是通用已开放能力。Demo 使用文字输入。未来接入语音时，必须核对平台支持与当前插件批准，不能继承其他插件的 Voice 权限。

## 5. 扩展为新岗位

新岗位的最小配置包括资料字段、标准记录、默认展示、岗位提示词、Skill、SOP 和公司设置定义。业务集成还应明确资料来源授权、清洗规则、错误恢复和外部写入确认。

1. 梳理岗位的真实资料类型和标准字段。
2. 在开发模式配置字段与展示，使用虚构资料验证清洗。
3. 配置提示词、Skill 和 SOP，检查事实与推测的区分。
4. 导出岗位配置，检查其中的公司机密和身份信息。
5. 使用 `scaffold` 命令生成新 `appId` 的插件，并填入自己的发布者身份。
6. 在生成目录安装依赖，运行测试、类型检查、CLI 校验和构建。
7. 验证 HTML 完整交互，再单独处理平台批准、安装和真实模型验收。

生成器只复制静态模板白名单。它更新新身份、默认岗位和包名，把 `file:` 依赖重定位为输出目录的相对路径。它不复制依赖目录、私有身份、原始公司资料、密码、缓存或构建产物。已有输出目录会被拒绝。首次安装在输出目录生成自己的锁文件。

### 5.1 外部资料适配合同

`src/source-adapter.ts` 将资料获取与三阶段业务核心分开。`SourceAdapter.read()` 接受取消信号、最大文件数和单份字节预算，返回 `{ name, mimeType?, bytes }` 数组。`ingestSourceBatch(controller, adapter, signal?)` 一次接纳最多 20 份，每份最多 128 KiB，并返回已保存的来源 ID。采集器应在读取和下载时执行预算限制，不能依赖最终入库检查限制远程下载量。

适配器只返回原始字节。它不能通过该接口修改标准记录或调用 Agent。入库后，调用方另行安排整理。相同内容依赖 SHA-256 去重，重试不会创建重复原件。

原件逐份提交。后续文件失败时，已经保存的原件继续保留。取消在读取前后与每份入库前检查，正在入库的单份资料仍可能完成保存。调用方应展示实际保存结果，不能把整批失败解释成全部回滚。

本地 fixture 验证同内容重试与采集前取消。当前没有真实邮箱、网盘或远程 API 采集器，也没有后台调度、凭据管理和自动重试服务。默认包不声明网络端点。接入真实来源需要新增采集器，并单独核对网络能力、来源授权、用户同意与运行时支持。

“任意岗位”表示核心模型可以复用，不表示所有岗位的采集器和清洗器已经实现。邮箱、网盘、定时采集、OCR、复杂表格、跨表关联和外部工具均需各自实现与授权。HTML 定制改变展示，不能自动产生业务数据合同。

## 6. 验证与未验证范围

本地验证入口位于 [模板 README](../plugins/ai-employee/README.md)。单元测试覆盖原始字节、资料去重、金额精度、整理失败、记录版本、恢复、密码锁定、配置导出、静态模板生成和 Agent 取消。CLI 检查默认最小权限包。未批准真实 Agent 候选的 `APP_CAPABILITY_NOT_GRANTED` 是单独的拒绝验证。

HTML 交互验证应完成导入、整理、编辑、Agent 分析、确认报告、导出、刷新恢复以及开发模式锁定。Mock Host 和浏览器本地存储只能证明其对应路径。测试结果须绑定本次输入与版本，不继承历史报告。

当前未验证：真实 Host 安装生命周期、平台冻结包批准、签名、真实外脑模型调用、Voice、邮件与定时采集、云端保存、多用户访问、法律税务正确性、公开分发及商店上架。各项需要独立证据。
