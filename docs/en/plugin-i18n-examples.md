# Language pack examples

> English reading guide. The [complete Chinese specification](/plugin-i18n-examples) remains the authoritative source for exact fields, examples, implementation status, and historical details. This page is a concise guide, not a full translation.

## Learn from the official reference plugins

- Use the examples to understand how language resources, Host language changes, and localized plugin metadata fit together.

- Keep the translation key structure consistent across languages and keep plugin identity separate from display labels.

- Verify the packaged resources, fallback behavior, settings text, status states, and real language-switch interactions.

- An example's local source state is not proof that its candidate package is approved, installed, or publicly released.
