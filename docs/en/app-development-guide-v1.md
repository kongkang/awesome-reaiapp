# Complete development guide

> English reading guide. The [complete Chinese specification](/app-development-guide-v1) remains the authoritative source for exact fields, examples, implementation status, and historical details. This page is a concise guide, not a full translation.

## Go from an idea to a testable plugin

- Start with a small useful behavior, then establish project structure, identity, lifecycle, and the minimum capabilities it needs.

- Keep the interface restrained and reuse platform tokens and contracts. Implement actual loading, failure, empty, and permission states.

- Build and validate independently. Use real Host interactions to verify behavior that fixtures and source tests cannot establish.

- Finish with consistent package identity, reproducible output, user-facing release notes, and a formal review candidate. Read the Chinese guide for the full worked example.
