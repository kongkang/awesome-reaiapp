# Driver 订阅、积分与云服务

Driver 的云服务支持按量使用：**没有订阅也可以消耗积分，积分不足时由服务端拒绝请求。** 订阅不是云模型、联网搜索、网页抓取或云识别的统一使用门槛。正常的登录、权限、项目访问和服务健康检查仍然适用；有积分不保证任意请求都能成功。

本文描述接入按量付费版本的行为。旧客户端需升级到包含此功能的版本；文档更新或代码合并不代表安装包已发布。插件更新通过各自的发布流程交付。

## 订阅与积分如何配合

| 情况 | 行为 |
|---|---|
| 没有订阅或订阅到期 | 仍可进入按量计费，由具体请求检查积分是否足够 |
| 有有效订阅 | 显示订阅权益，继续服从服务端实际计费和可用性规则；不代表免费或无限使用 |
| 积分不足 | 服务端计费拒绝，不应提示购买订阅；补足对应计费团队的积分后重试 |
| 订阅或余额读取失败 | 页面显示未知或错误，不伪装成无订阅或零积分；页面快照不控制云请求准入 |

本地功能和用户自己的 Desktop 账户不受此订阅页限制。Driver 订阅状态也不代表第三方插件商品的购买状态。

## 查看订阅和余额

从 Driver 左下角账户菜单打开「订阅」。页面显示默认个人团队的订阅、最近账单及积分余额；没有套餐时说明仍可按量使用。余额包括赠送和购买两部分，账期截止不表示所有购买积分到期。

只显示**默认个人团队**的余额。项目服务（例如联网搜索、抓取）可能扣项目所属团队，不能用当前页面余额推断所有项目的可用额度。最终费用和余额是否足够，以具体请求的服务端计费为准。

充值或管理订阅使用页面中的网页管理入口，在浏览器中正常登录对应账户和团队。Driver 不自行生成付款地址，也不在网页 URL 中携带 OAuth token。

## 升级后提示重新授权

新版 Driver 需要只读权限 `billing:read`。旧会话不会因为客户端升级自动获得新增权限：

1. 在 Driver 的「账户」中退出当前会话，再正常登录。
2. 核对授权页的应用与账号，确认权限中包含「读取订阅与账单摘要」。
3. 返回 Driver，重新打开「订阅」并刷新。

若提示应用定义已变化，重新发起一次授权以读取新的应用定义。若反复失败，记录错误码并联系支持，不要反复购买订阅或重置密码。若提示当前版本未启用订阅读取，则需升级客户端；仅重新登录不能补上构建时缺失的能力。

## 插件开发者须知

- `billing:read` 是正式 Driver 的受限 OAuth 权限，**不是普通插件可申请的公开余额 API**。本次没有新增插件 SDK 的订阅或余额接口。
- 插件使用既有云能力及权限声明；不要读取 Host 凭据、直接调用内部账单接口，或按套餐名称、余额快照自行增加订阅门禁。
- Host 的 `GET /billing/summary` 将余额整数以毫积分传输：`1000 毫积分 = 1 显示积分`。此处说明展示单位，不授权插件访问该接口。缺失、null 或非法余额是未知；0 和有效负余额保留真实含义。
- 处理额度不足时引导补充正确团队的积分。处理 `AI_SUBSCRIPTION_REQUIRED` 或 `web_access_subscription_required` 等旧后端兼容错误时，说明服务端尚未开放按量能力，不要要求先购买订阅。其他网络、限流或服务故障分别按 [云错误合同](plugin-api-reference-v1.md) 处理。
- 订阅权益占位字段不代表已获得权益，`cloudAccess` 表达订阅权益状态，不是所有云请求的准入开关。

## 云转写的当前价格（源码候选）

转写设置展示的是已认证当前账号的有效美元美分/秒，而不是永久免费标签。数值0仍产生用量与金额0的账证，记录订阅原因及价格版本；订阅政策的有效价格变为0.1时，普通请求正常计费。没有可信当前报价时显示不可用，不按模型名称、默认项或套餐名猜测。

`isDefault` 只表示当前默认选项，可以免费也可以收费。已有明确的 `free-only` 选择及录音重试保留免费限定，价格变更后拒绝执行；明确选择不同选项采用新项的普通策略。录音快照和重试不会因为页面刷新自动丢掉原约束。服务端最终执行报价与账证为准，设置页报价不承诺未来永远为0。

该说明对应待交付的新 Host/Voice 源码，不代表当前签名安装包已经更新。
