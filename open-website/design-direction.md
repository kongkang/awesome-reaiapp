# ReAI Open 首页调研与方向

调研日期：2026-10-02。以下信息结构来自联网读取的官方页面；视觉观察补充使用内置浏览器查看 Dify Marketplace 与 Raycast Store。借鉴组织方式，界面不复制参考站点。

## 参考与取舍

| 官方参考 | 可观察的结构 | 本站采用 | 本站暂不采用 |
| --- | --- | --- | --- |
| [Dify Marketplace](https://marketplace.dify.ai/) | 搜索插件 / 模板，热门与最近发布，类型分类，插件卡片 | 搜索、分类、精选插件与应用案例分开展示 | 首页堆大量榜单、自动轮播和未经验证的安装量 |
| [Raycast Store](https://www.raycast.com/store) | 精选插件、完整目录、近期 / 热门、作者与安装入口；深色产品展示 | 每张卡片说明用户收益，进入具体插件页，精选内容帮助开始 | 将整站设成深色；生产安装能力未接好前放假安装按钮 |
| [Hugging Face](https://huggingface.co/) / [Spaces](https://huggingface.co/spaces) | 应用与开发资源共存，内容分类明确，演示有独立详情 | 案例有具体任务、用到的插件与结果；文档常驻导航 | 模型/数据集式的高密度研究信息流 |
| [Coze](https://www.coze.com/) | 官方定位强调 AI 应用搭建与发布；正文抓取有限 | 开发者入口使用具体动词 | 不以不足的可读内容推断细节布局 |

旧文档地址 [ai-board.reai.com/docs](https://ai-board.reai.com/docs/) 本次 web 读取返回错误；迁移目标依据用户确认与仓库中现有 VitePress 源码，不声称已在线迁移。

## 三种方向比较

| 方向 | 优势 | 当前取舍 |
| --- | --- | --- |
| A · 浅色产品画廊（推荐） | 插件识别度高、中文阅读清楚，能兼容案例和文档入口 | 本次制作可点击首页草稿 |
| B · 深色开发者控制台 | 技术氛围强，适合 API / 算力平台 | 开放平台以发现应用为主，控制台可日后单独设计 |
| C · 高密度社区市场 | 大量内容、排序和筛选效率高 | 初期内容规模及真实热度数据未确定，未来目录页采用 |

推荐是设计判断，不是参考站点给出的结论。ui-ux-pro-max 的检索建议提供了清晰 CTA、留白、可访问性和响应式检查；通用的紫色 AI 配色未采用，使用本稿自定义橙色点缀。页面配色为方向候选。品牌图形使用用户于2026-10-02确认的既有黑绿括号脸：候选1用于页面 Logo，候选3用于站点图标；保留原始形状和配色，取消自造标识。候选4的旧绿色麦克风品牌标识废弃，不再使用。

## 首页信息架构

1. 导航：ReAI Open / 插件 / 应用案例 / 开发者 / 文档。
2. 首屏：「让 AI 的能力，走进每一种工作。」主入口探索插件，次入口开发插件；右侧以语音、浏览器和终端组合演示能力。
3. 精选插件：图标、名称、简短用途、类别；原型用真实仓库名称和图标，公开页面仅展示真实已发布数据。
4. 应用案例：以任务切入，说明插件组合与用户结果。初稿仅展示场景示例，后续案例需内容审核和真实截图/证据。
5. 开发者：开发规范 → API → 审核提交；将现有文档作为内容源，未来归入 `/docs/`。
6. 页脚：平台定位、插件、案例、开发文档和后续可核实的运营信息。

## 视觉与交互

- 暖白背景 `#FAF9F6`、墨色正文 `#232323`、朱橙 `#BC3F25`，辅助浅绿 / 浅紫只用于演示面板。
- 内容宽度 1160px；桌面左右首屏、三列精选卡片；平板与手机逐步转为单列，中文标题不强制截断。
- 系统中文无衬线字体；英文辅助标题使用系统衬线，避免外部字体加载依赖。
- 图标采用仓库实际插件 PNG；流程演示用 HTML/CSS，非实际插件截图。无自动轮播、无大量背景动效。
- 所有链接、筛选、搜索、弹窗支持键盘；明显焦点环、至少44px点击目标，尊重减少动态效果。此稿主推浅色，暗色主题留待方向确认。

## 页面与内容合同

应用详情 `/apps/<appId>` → 同应用更新日志 `/apps/<appId>/changelog?version=…`；案例 `/showcase/<slug>`；文档 `/docs/`。具体规则见[插件设置页规范](../docs/plugin-settings-and-release-notes-v1.md)。原型不提前请求这些未部署路由。

公共版本取发布 Catalog，设置页显示安装包版本；草稿和已发布记录分别处理。送审自动生成的介绍先成为版本文档，获准并显式发布后才作为公共日志展示。文档迁移保持旧链接可追溯。
